# homebrew-buzzr

Homebrew tap for [buzzr](https://github.com/buzzzr/buzzr), a terminal client for [Buzz](https://github.com/block/buzz).

```bash
brew install buzzzr/buzzr/buzzr
```

or

```bash
brew tap buzzzr/buzzr
brew install buzzr
```

Upgrade with `brew update && brew upgrade buzzr`.

The formula installs the prebuilt binary from each [buzzr release](https://github.com/buzzzr/buzzr/releases)
(macOS and Linux, arm64 and x86_64), so there is nothing to compile.
